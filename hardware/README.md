# 硬件设计资料待提供

本包仅有开发板接线说明（docs/WIRING.md），没有经核实的最终 PCB 工程。
请队友提供并核实：

1. 立创 EDA/EasyEDA 原始工程及工程版本，原理图源文件与可读 PDF。
2. PCB 原始设计、Gerber、钻孔、板框/叠层及尺寸说明。
3. BOM（器件规格、封装、数量、可采购料号）和贴片坐标/CPL。
4. 最终 GPIO 网络表、电源/USB/背光电路、编码器与独立开关端子定义。
5. 实物/装配照片、设计作者/授权及拟采用的硬件设计许可证。

当前 GPIO7/8、1/2/21 为开发板验证接线，不能冒充最终 PCB 网络。不得使用触摸实验中的最终 PCB 候选引脚代替未提供的原理图。
请取得文件后放入 hardware/ 下并更新清单；没有这些资料，本包不能用于完整 PCB 复刻制造。
